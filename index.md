# About This Site

## Goal
This is my personal portfolio website where I share Python code examples and data analysis projects through Jupyter notebooks. The site serves as both a learning resource for others and a documentation of my technical journey.

## Technical Details
This site is built using:
- **Jekyll** with the So Simple Theme
- **GitHub Pages** for hosting
- **Jupyter Notebooks** converted to markdown for code demonstrations
- **Collections** to organize different types of content
- **Tags and Categories** for easy navigation

### Site Structure
- **Notebooks**: Python code examples and data analysis projects
- **Posts**: General technical writing and tutorials
- **Categories**: Content organized by main topics
- **Tags**: Detailed topic-based navigation
